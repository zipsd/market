# Market

Лёгкий статический магазин файлов по школьным предметам на HTML, CSS и vanilla JavaScript. Сайт можно сразу разместить через GitHub Pages.

## Настройка магазина

Все основные настройки находятся в начале файла `script.js`.

- **Товары:** изменяйте объекты в массиве `PRODUCTS`. У каждого товара есть `id`, `title`, `description`, `subject`, `format` и `price`.
- **Разделы по предметам:** укажите предмет в поле `subject` товара. Кнопка нового раздела появится автоматически.
- **Цена:** измените значение `price` у нужного товара в массиве `PRODUCTS`.
- **Сеть оплаты:** замените `YOUR_NETWORK` в `STORE_CONFIG.PAYMENT_NETWORK`.
- **Публичный адрес кошелька:** замените `YOUR_PUBLIC_WALLET_ADDRESS` в `STORE_CONFIG.WALLET_ADDRESS`.
- **Контакт:** замените `YOUR_CONTACT` в `STORE_CONFIG.CONTACT` на электронную почту, имя пользователя Telegram или другой способ связи.
- **QR-код:** при необходимости замените блок-заглушку в `index.html` изображением QR-кода публичного адреса.

Добавляйте на сайт только **публичный адрес для получения платежей**. Никогда не размещайте seed phrase, private key, секретный API-ключ или другие конфиденциальные данные во frontend-файлах и публичном репозитории GitHub.

Платные документы специально не включены в сайт. Их следует отправлять покупателю лично только после подтверждения оплаты.

## Публикация через GitHub Pages

1. Отправьте эти файлы в корень репозитория `market` на GitHub.
2. Откройте репозиторий и перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации. Адрес сайта: `https://zipsd.github.io/market/`.

Перед публикацией замените значение `og:url` в `index.html` на настоящий адрес сайта.
